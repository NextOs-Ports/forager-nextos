Forager owner data / dados do dono
==================================

EN: Put a lawful Android 1.0.13 package you own in this directory and launch
Forager Nuclear. The filename does not matter. NXExtract 1.2.6 accepts a loose
APK or the base APK discovered inside APKM/APKS/XAPK, then validates package
com.humblebundle.forager, ABI armeabi-v7a and the exact 24 members consumed by
the runner. The package is never deleted. No game data belongs in the source
repository or release.

PT-BR: Coloque nesta pasta um pacote Android 1.0.13 adquirido legalmente e abra
Forager Nuclear. O nome do arquivo não importa. O NXExtract 1.2.6 aceita APK
solto ou o APK base encontrado dentro de APKM/APKS/XAPK e valida o pacote
com.humblebundle.forager, a ABI armeabi-v7a e os 24 membros exatos usados pelo
runner. O pacote nunca é apagado. Nenhum dado do jogo entra no repositório ou
na release.
